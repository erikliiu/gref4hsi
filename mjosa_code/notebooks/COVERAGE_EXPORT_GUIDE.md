# Coverage Statistics Export System

## Overview

A new system has been added to export classification coverage statistics from all classification notebooks to enable cross-model and cross-transect comparison.

## What Was Added

### 1. Export Cells in Existing Notebooks

New cells were added at the **end** of each classification notebook to export coverage percentages to CSV files:

#### **Notebook 6 (057 baseline)**
- **Location**: Two new cells at the very end
- **Exports**: `coverage_stats/057_on_057_coverage.csv`
- **Contains**: Coverage percentages for full 057 transect using 057 model
- **Format**: One row per class with model, region, class name, pixel count, and percentage

#### **Notebook 9 (028 on crops)**
- **Location**: Two new cells at the very end
- **Exports**: `coverage_stats/028_on_028_coverage.csv`
- **Contains**: Coverage percentages for each of the 4 crop regions using 028 model
- **Format**: Multiple rows (one per class per crop region)

#### **Notebook 10 (028→057 transfer)**
- **Location**: Two new cells at the very end
- **Exports**: `coverage_stats/028_on_057_coverage.csv`
- **Contains**: Coverage percentages for full 057 transect using 028 model
- **Format**: One row per class

#### **Notebook 11 (057→028 transfer)**
- **Location**: Two new cells at the very end
- **Exports**: `coverage_stats/057_on_028_coverage.csv`
- **Contains**: Coverage percentages for 028 crop regions using 057 model
- **Format**: Multiple rows (one per class per crop region)

### 2. New Summary Notebook

**`12_coverage_summary.ipynb`** - A completely new notebook that:

- **Loads** all CSV files from `coverage_stats/` directory
- **Combines** data into a single dataframe
- **Creates comparison tables** showing:
  - Overview of all models and regions
  - Full transect comparison (057 only)
  - Crop region comparison (028 crops with both models)
- **Exports summary tables**:
  - `combined_coverage_all.csv` - Complete dataset
  - `comparison_full_transects.csv` - Pivot table for full transects
  - `comparison_crop_regions.csv` - Pivot table for crop regions
- **Generates visualizations**:
  - Bar charts comparing model performance
  - `full_transect_comparison.png`
- **Calculates statistics**:
  - Average coverage by class
  - Sediment dominance metrics
  - Non-sediment feature percentages
  - Model sensitivity differences

## How to Use

### Step 1: Run Classification Notebooks

Run these notebooks in order to generate the coverage CSV files:

1. **Notebook 6** - Run all cells, especially the new export cell at the end
2. **Notebook 9** - Run all cells, especially the new export cell at the end
3. **Notebook 10** - Run all cells, especially the new export cell at the end
4. **Notebook 11** - Run all cells, especially the new export cell at the end

After running each notebook, you should see:
```
✅ Coverage statistics exported!
   File: ./coverage_stats/[filename].csv

📊 Coverage Summary:
...
```

### Step 2: Run Summary Notebook

Open **Notebook 12 (`12_coverage_summary.ipynb`)** and run all cells.

This will:
- Load all 4 CSV files
- Create comprehensive comparison tables
- Generate visualizations
- Export summary tables ready for your paper

### Step 3: Use Results in Paper

The exported files can be directly imported into your paper:

- **Tables**: Use the CSV files in `coverage_stats/` folder
- **Figures**: Use the PNG file `full_transect_comparison.png`
- **Statistics**: Copy the printed summary statistics from notebook 12

## CSV Format

Each coverage CSV has these columns:

| Column | Description | Example |
|--------|-------------|---------|
| `notebook` | Source notebook | `"6_svm_057_general"` |
| `model` | Model applied to data | `"057_on_057"` |
| `region` | Classification region | `"full_transect"` or `"Crop 1 (Bomb 2 - Rust)"` |
| `class` | Class name | `"sediment"`, `"dark"`, etc. |
| `pixels` | Number of pixels | `868087` |
| `percentage` | Coverage percentage | `90.5` |

## Notes

- The `coverage_stats/` directory is automatically created if it doesn't exist
- CSV files are overwritten each time you run the export cells
- If a notebook hasn't been run, its CSV will be missing (notebook 12 will warn you)
- All percentages are calculated as (class_pixels / total_pixels * 100)

## Troubleshooting

**"ERROR: [variable] not found!"**
- Run the classification cells in that notebook first
- Make sure the entire pipeline completed successfully

**"Missing: [model_name]"**
- That notebook hasn't been run yet
- Run the corresponding notebook and its export cell

**Empty coverage_stats directory**
- No notebooks have exported yet
- Run at least one notebook's export cell to create the directory
